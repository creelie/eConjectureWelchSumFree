# The Welch function is not third-order sum-free

Submission package v1.2.0, 26 October 2026. Authors: Deep Bhattacharjee.

Target journal: **Finite Fields and Their Applications**. No journal submission has been made by this packaging work.

## Main files

- `WelchSumFree.pdf`: manuscript, single column, no marginal line numbers.
- `WelchSumFreetex.zip`: portable TeX sources for Overleaf and Hexagon; created only after the new Zenodo DOI is confirmed.
- `hexagonsubmissionform.md`: copy-ready fields and existing preprint identifier.
- `aiprovinance.md`: provenance and the retained human-understanding declaration.
- `journalsubmissiondetails.md`: journal portal, scope and submission checklist.
- `coverletterjournal.pdf` and `coverlettertex.zip`: prepared cover letter and TeX source.
- `journalaideclarationform.pdf`: prepared AI disclosure statement, not a signed publisher-issued form.
- `FORMAL-SCOPE.md`: precise verification scope.
- `DOI-RECEIPT.json` and `RELEASE-DOI.md`: final archival evidence, added after publication.
- `PACKAGE-MANIFEST.json`: checksums for the final package.

The manuscript reproduces the reduction to the linearised polynomial, proves the two-trace criterion and exact count, and applies the classical Weil bound. The Hou-Zhao preprint identifies the conjecture and prior work; its reduction is proved again in the manuscript rather than assumed.

The existing preprint is https://hexagonmath.org/2610.00472v1. The intended Hexagon revision is v2; it has not been submitted by this work. The author has no arXiv identifier for this paper.

The journal and Hexagon manuscripts are the same PDF and source. Formalisation files are linked through the existing repository rather than included in the Hexagon TeX ZIP. Original verification code remains in the repository.
